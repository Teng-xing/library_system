# 图书管理系统（C++ 面向对象实验）

一个基于 C++ 面向对象思想实现的图书信息管理项目。项目以 `Book` 类为核心，演示了**封装、构造函数重载、数据合法性校验、接口访问控制**等 OOP 基础能力，并在此之上规划了可落地的系统级扩展方向。

---

## 一、项目简介

本项目围绕"图书"这一业务实体进行抽象，将书名、ISBN、出版社、价格、页数、在馆状态等属性封装到 `Book` 类中，对外只暴露受控的 `set / get` 接口。当前版本重点验证类的设计与数据保护逻辑，后续可平滑扩展为支持借阅、归还、检索、持久化的完整图书馆系统。

- **编程范式**：面向对象（封装为主）
- **当前阶段**：领域类设计与核心校验逻辑验证
- **设计目标**：高内聚、低耦合，属性由类自身守护，外部无法非法写入

## 五、`Book` 类设计说明

**私有数据成员（外部不可直接修改）**

| 成员 | 类型 | 含义 |
| --- | --- | --- |
| `m_bookName` | string | 图书名称 |
| `m_isbn` | string | ISBN 编号 |
| `m_publisher` | string | 出版社 |
| `m_price` | double | 价格（元） |
| `m_pages` | int | 页数 |
| `m_available` | bool | 在馆状态：true 可借 / false 已借出 |

**对外接口分层**

- **构造层**：`Book()` 默认构造、`Book(...)` 带参构造。
- **写入层（set）**：每个属性一个 `set` 方法，关键属性在写入前做合法性判断，把"数据不合法"的风险拦在类内部。
- **读取层（get）**：均加 `const`，保证只读访问不改变对象状态。
- **业务层**：`checkIsbnValid()` 负责规则校验，`showInfo()` 负责对外展示。

> 设计要点：**校验逻辑内聚在类里**，调用方（如 `main`）不需要也无法绕过这些保护——这正是封装的价值。

## 七、设计亮点（已体现的工程实践）

1. **封装与信息隐藏**：属性私有化，外部只能通过受控接口读写，避免脏数据。
2. **构造函数重载**：支持"先建对象再填信息"与"一步到位建对象"两种用法。
3. **写入即校验的防御式编程**：价格、页数、ISBN 三处均在写入路径上拦截非法输入。
4. **const 正确性**：所有读取接口声明为 `const`，明确区分"只读"与"可改"操作。
5. **职责单一**：校验、打印、赋值各司其职，方法短小清晰。

## 八、可创新点与扩展规划

> 这是本项目从"类的演示"走向"真正图书管理系统"的核心方向。按**由易到难、由内到外**分层推进，每一点都在现有代码基础上可平滑落地。

### 🥇 方向 A：数据校验升级（现有雏形的深化，最易出成果）

- **A1. 标准 ISBN-13 校验位算法**
  现状仅判断"是否为 13 位纯数字"。可升级为国家标准 ISBN-13 的**模 10 加权校验**：前 12 位按"奇位 ×1、偶位 ×3"求和，用 10 减去和的个位得到校验位，再与第 13 位比对。从"格式校验"升级为"真实性校验"，技术含金量明显提升。
- **A2. 用异常替代静默兜底**
  现在非法价格/页数被静默改成 0 或 1，调用方无感知。可改为 `throw` 非法参数异常，由 `main` 侧 `try/catch` 捕获并提示，让错误显性化、可追溯。

### 🥈 方向 B：从"单本书"到"图书馆"（架构级升级）

- **B1. 引入书库管理类 `Library / BookManager`**
  用 `vector<Book>` 容纳多本图书，提供**增加、删除、修改、查找**四大基础操作——这才是"管理系统"的本体。
- **B2. 多维度检索**
  支持按书名**模糊匹配**、按 ISBN **精确匹配**、按出版社**筛选**，并可按价格 / 页数排序输出。
- **B3. 借阅—归还业务闭环**
  新增 `Reader`（读者）与 `BorrowRecord`（借阅记录）类：借书时检查 `m_available` 是否为真、占用副本；还书时恢复状态；记录"谁、何时、借了哪本书"。
- **B4. 逾期判定**
  基于借阅时间与应还时间差，自动判定逾期并计算滞纳金，把系统从"记录"升级为"业务引擎"。

### 🥉 方向 C：持久化与交互（让系统可用）

- **C1. 文件持久化存储**
  将书库以文本或二进制方式读写到磁盘，**程序关闭后数据不丢失**——这是单机管理系统的必备能力。
- **C2. 交互式控制台菜单**
  用循环菜单替代现在写死的 `main`：用户可选择"录入图书 / 查询 / 借书 / 还书 / 退出"，成为一个可实际操作的小系统。

### 方向 D：面向对象进阶（展示 OOP 深度）

- **D1. 继承与多态**：派生 `EBook`（电子书）继承 `Book`，增加"文件大小、格式、下载链接"属性，用虚函数 `showInfo()` 实现不同类型图书的差异化打印。
- **D2. 运算符重载**：重载 `>` / `<` 按价格比较两本书，使排序更自然。
- **D3. 智能指针管理**：对动态分配的图书改用 `unique_ptr` / `shared_ptr`，杜绝内存泄漏。

### 方向 E：数据洞察与体验（加分项）

- **E1. 统计报表**：一键输出在馆率、馆藏均价、最贵图书、各出版社藏书分布等。
- **E2. 界面升级**：从控制台向 Qt 图形界面或 Web（前端 + C++ 后端接口）演进。

> **推荐落地路线**：先做 **A1（ISBN 校验位）** 与 **B1 + C2（书库类 + 交互菜单）**，两点即可让项目从"实验作业"质变到"完整可演示系统"；再视时间推进 B3、C1。

## 九、快速开始

1. 用 Visual Studio 打开 `libray1.vcxproj`。
2. 选择 `x64 → Debug` 配置，生成解决方案。
3. 运行 `libray1.exe`，在控制台查看三类图书的信息与 ISBN 校验结果。

无需安装任何第三方依赖，直接编译运行即可。
