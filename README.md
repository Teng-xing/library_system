# 图书管理系统 实验二
## 实验目的
理解C++类之间**组合关系（has-a）**与**依赖关系（use-a）**的概念，掌握类之间关联的编程实现。

## 类设计说明
1. **Book 图书类**
本类为实验一完整代码，**未做任何修改**。
成员变量：图书名称、ISBN编号、出版社、价格、页数、是否可借状态。
成员功能：默认构造函数、带参重载构造函数、ISBN合法性校验、set/get成员函数、打印图书信息showInfo。

2. **Library 图书馆类【组合 has-a】**
组合关系：图书馆整体包含多本图书，Library内部使用`vector<Book>`保存Book对象，属于整体与部分的组合。
- addBook(Book b)：图书入库，添加图书到馆藏列表
- findBook(string isbn)：根据ISBN编号查找图书，返回图书指针
- showAllBook()：遍历输出图书馆所有藏书信息

3. **Reader 读者类【依赖 use-a】**
依赖关系：读者本身不拥有图书对象，仅在借书、还书的时候，通过Book*指针临时使用Book对象。
- borrowBook(Book* b)：借书，判断图书是否可借，修改图书借阅状态
- returnBook(Book* b)：还书，归还图书并恢复图书可借状态
- showBorrow()：展示该读者当前借阅的全部图书

## 程序运行流程
1. 创建若干图书对象；
2. 创建图书馆对象，将图书批量入库；
3. 展示图书馆全部藏书；
4. 创建读者对象，执行借书操作，校验图书借阅状态；
5. 查看读者借阅清单；
6. 执行还书操作，归还图书；
7. 再次借书，测试归还后的图书可以被其他读者借阅。

## 功能清单
1. 图书信息录入
2. 图书入库管理
3. 展示全部馆藏图书
4. 根据ISBN查找指定图书
5. 读者借书（状态校验）
6. 读者归还图书
7. 查看读者借阅列表
